## Senior Software Engineer - Full Stack

**Company**: Tech Innovations Inc.  
**Location**: San Francisco, CA (Hybrid)  
**Employment Type**: Full-time  
**Experience Level**: 5-7 years

### About the Role

We are seeking an experienced Senior Software Engineer to join our growing engineering team. You will be responsible for designing, developing, and maintaining our core web applications that serve millions of users worldwide. This role requires strong technical skills, leadership abilities, and a passion for building high-quality software.

### Key Responsibilities

- Design and develop scalable web applications using modern technologies
- Lead technical discussions and architectural decisions
- Mentor junior and mid-level engineers
- Collaborate with product managers and designers to deliver features
- Write clean, maintainable, and well-tested code
- Participate in code reviews and ensure best practices
- Optimize application performance and reliability
- Contribute to technical documentation and knowledge sharing

### Required Qualifications

- Bachelor's degree in Computer Science or related field
- 5+ years of professional software development experience
- Strong proficiency in Python and/or JavaScript
- Experience with modern web frameworks (Django, React, Node.js)
- Solid understanding of database design (PostgreSQL, MongoDB)
- Experience with cloud platforms (AWS, GCP, or Azure)
- Proficiency with Git and version control
- Strong problem-solving and debugging skills
- Excellent communication and teamwork abilities

### Preferred Qualifications

- Experience with microservices architecture
- Knowledge of containerization (Docker, Kubernetes)
- CI/CD pipeline implementation experience
- AWS certification
- Experience with agile/scrum methodologies
- Technical leadership or mentoring experience
- Open source contributions
- Experience with performance optimization

### Technical Stack

- **Backend**: Python, Django, Node.js, Express
- **Frontend**: React, TypeScript, HTML/CSS
- **Database**: PostgreSQL, Redis, MongoDB
- **Cloud**: AWS (EC2, S3, Lambda, RDS)
- **DevOps**: Docker, Kubernetes, Jenkins, GitHub Actions
- **Tools**: Git, JIRA, Confluence, Slack

### What We Offer

- Competitive salary range: $140,000 - $180,000
- Equity/stock options
- Comprehensive health, dental, and vision insurance
- 401(k) with company match
- Flexible work arrangements (hybrid)
- Professional development budget
- Unlimited PTO policy
- Modern tech stack and tools
- Collaborative and inclusive culture

### How to Apply

Please submit your resume and a brief cover letter explaining why you're interested in this role and what makes you a great fit.
